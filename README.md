# 宋智峰 · 工程作品集

工业工程、制造、质量、供应链与现场工程作品集，包含九个项目案例、九份原始报告和 22 页 PDF 提交版。Capstone 已注明项目负责人职责。

## 网站入口

- **[在线浏览作品集](https://song-zhifeng.github.io/)**：适合放入简历、网申或发送给招聘方。
- **[打开 PDF 提交版](https://song-zhifeng.github.io/reports/portfolio.pdf)**：22 页完整作品集，可直接下载。
- **[项目目录](https://song-zhifeng.github.io/#directory)**：按岗位方向筛选，或搜索项目内容。
- **[原始项目报告](https://song-zhifeng.github.io/#reports)**：查看和下载九份原始报告。

网页支持逐个项目阅读、连续阅读、返回目录、图片放大及原报告页码跳转。

## 后续更新

网站已通过 GitHub Pages 发布。更新 `main` 分支中的网站文件后会自动部署，无需重新创建网站。

发布状态可在仓库 [Actions](https://github.com/song-zhifeng/song-zhifeng.github.io/actions) 中查看。Pages 使用 `main` 分支的 `/(root)` 目录。

## 文件

- `index.html`：作品集首页与全部案例。
- `assets/`：本地字体、样式、交互脚本与项目图片。
- `reports/portfolio.pdf`：22 页 PDF 提交版。
- `reports/` 中其余九份文件：原始项目报告，保留原内容。

页面使用相对路径，不依赖外部字体或前端框架；报告只在打开或下载时请求。
