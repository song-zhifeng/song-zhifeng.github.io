# 宋智峰 · 工程作品集

适合 GitHub Pages 的静态网站，包含九个项目案例、九份原始报告和 22 页 PDF 提交版。Capstone 已注明项目负责人职责。

## 网站入口

启用 GitHub Pages 后的访问地址：<https://song-zhifeng.github.io/>。

首次启用：仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。完成部署后，以该设置页的 Visit site 为准。

后续更新 `main` 分支中的网站文件即可自动发布，无需重新创建网站。

## 文件

- `index.html`：作品集首页与全部案例。
- `assets/`：本地字体、样式、交互脚本与项目图片。
- `reports/portfolio.pdf`：22 页 PDF 提交版。
- `reports/` 中其余九份文件：原始项目报告，保留原内容。

页面使用相对路径，不依赖外部字体或前端框架；报告只在打开或下载时请求。

GitHub 官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
